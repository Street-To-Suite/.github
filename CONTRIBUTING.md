# Bijdragen

## Afspraken

- Nooit rechtstreeks op `main` pushen.
- Werk op branches: `feature/naam`, `fix/naam`.
- Altijd een PR openen, met minstens 1 review van een teamgenoot.
- Alleen de lead mergt.
- Geen force-push op `main`.
- Duidelijke commit-berichten.

## Werkwijze

1. Maak een branch vanaf `main`: `git checkout -b feature/naam`
2. Commit je werk met duidelijke berichten (bijv. `Voeg login-validatie toe`).
3. Push de branch en open een Pull Request (de PR-template vult zich automatisch in).
4. Vraag een review aan een teamgenoot en verwerk de feedback.
5. Na goedkeuring mergt de lead.

## Issues

Gebruik de templates om een bug of feature aan te maken.
